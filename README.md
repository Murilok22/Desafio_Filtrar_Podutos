## 📌 Sobre o projeto

Este projeto explora os dados de vendas da Geek Store para identificar padrões e gerar métricas que ajudam a compreender o desempenho dos produtos. A análise utiliza **Pandas** para inspecionar, transformar, filtrar e preparar os dados para visualização.

## ✨ Análises realizadas

| Área | O que é analisado |
| --- | --- |
| **Visão geral** | Estrutura, tipos de dados e estatísticas descritivas do conjunto. |
| **Avaliações** | Cinco produtos com as maiores e as menores avaliações. |
| **Receita** | Receita total por produto. |
| **Lucratividade** | Lucro unitário (preço de venda menos custo de fabricação) e lucro total considerando o volume vendido. |
| **Segmentação** | Produtos da categoria de peças para PC, para apoiar análises e campanhas direcionadas. |
| **Exportação** | Dados tratados em CSV para análises posteriores em ferramentas como Power BI ou Tableau. |

## 🚀 Como executar

### Pré-requisitos

- Python 3 instalado.
- Arquivo de dados `vendas_geek_store.csv`.

### 1. Clone o repositório

```bash
git clone https://github.com/Murilok22/Desafio_Filtrar_Podutos.git
cd Desafio_Filtrar_Podutos
```

### 2. Instale o Pandas

```bash
python -m pip install pandas
```

### 3. Prepare os dados e execute

Coloque `vendas_geek_store.csv` no local esperado pela análise e execute o script ou notebook do projeto. Os resultados podem ser exportados para `vendas_geek_novo.csv`.

> **Importante:** verifique no script ou notebook os nomes das colunas e o caminho de entrada esperados. O arquivo CSV de origem não está incluído neste repositório.

## 📦 Resultado

O arquivo `vendas_geek_novo.csv` reúne os dados tratados e as métricas calculadas, prontos para exploração ou visualização em ferramentas de BI.

## 🎯 Objetivo

Praticar análise e tratamento de dados com Pandas e explorar como avaliações, vendas, receitas e custos podem ajudar a entender o desempenho de um catálogo de produtos.
